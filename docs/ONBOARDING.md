# Onboarding

Eight screens: Welcome, Interests, First stamp, Collected vs Verified, Pick your cover, Passport ready, then (only with `FeatureFlags.plusPaywallEnabled`) the Plus paywall with the "Start free, upgrade later" exit sheet over it. With the flag off, Passport ready finishes onboarding.

## Where things live

| What | Where |
|---|---|
| Pure rules (routes, flags, cover styles, interests) | `Domain/Onboarding/` |
| Progress persistence (one `PassportProfile` row) | `Data/Persistence/OnboardingRepository.swift` |
| Screens | `Features/Onboarding/{Flow,Welcome,Interests,FirstStamp,Verification,Cover,PassportReady,Plus,ExitSheet}` |
| Shared components, tokens, stamps | `Core/DesignSystem/Onboarding/{Tokens,Typography,Components,Motion,Stamps,Passport}` |
| StoreKit 2, fake clients, reminders | `Platform/Subscriptions`, `Platform/Reminders` |
| Plus test store | `Resources/Plus.storekit` (scheme and StoreKitTest only, not bundled) |

Colours are Color Sets generated by `Tools/make_onboarding_colors.py` into `Assets.xcassets/{Colors,Welcome,Onboarding}` and read through `OnbColor`, `WelcomeColor` and (stamp art only) `OBColor`. Text is the system font; stamp captions use bundled Newsreader (`FontRegistration` checks it resolves).

## Data

- The first stamp is a normal `UserStamp` saved through `PassportStore`; nothing reveals before the save returns.
- The selected cover is stored in `OnboardingModel.coverStyle` on every selection; a Plus cover without Plus is shown as the first free cover (`CoverEntitlementResolver`).
- "Plus paywall first shown" and "exit sheet shown" are kept in `UserDefaults`, not in the SwiftData store (changing that schema would stop existing passports from opening).
- `finish()` sets `PreferencesStore.hasCompletedOnboarding` and the main app's cover style.

## Flags and launch arguments (DEBUG only)

| Argument | Effect |
|---|---|
| `-ff-plus`, `-ff-coasts` | Turn on the Plus paywall and the Coasts pack (off by default; the Xcode Run scheme passes both) |
| `-uitest-reset`, `-uitest-reduce-motion`, `-uitest-onboarding-start <route>` | Reset data, force reduced motion, jump to a screen |
| `-uitest-subscriptions <scenario>`, `-uitest-packs <scenario>`, `-uitest-notifications authorized\|denied`, `-uitest-pack-art`, `-uitest-exit-shown` | Fake store and notification state for UI tests |
| `-uitest-location <script>` | Scripted device location |

## Known gaps

The Coasts pack has no artwork of its own, so its row stays hidden (`Pack.hasRealArt`). Terms and Privacy point at placeholder URLs in `AppConfiguration`. Not verified on a device: haptics, tilt, frame rate, a real purchase, VoiceOver, Dynamic Type at the largest sizes.
